Array & Function Visual Layout

A simple frontend practice project created using HTML and CSS.

This project displays two visual sections side by side — one for Arrays and another for Functions. The main focus of this project was to practice webpage structure, image placement, CSS sizing, spacing, and basic layout techniques.

🚀 Features
Simple and clean webpage layout
Array and Function visual sections
Images displayed using HTML
CSS used for layout and styling
Basic responsive structure planned for future improvement
Beginner-friendly frontend project
🛠️ Technologies Used
HTML5
CSS3
JavaScript
